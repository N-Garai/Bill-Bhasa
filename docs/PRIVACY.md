# Privacy — your papers stay yours

- Photos and results live in **your own** database (local file at home,
  your own Neon project in production). They are never sent to ad networks,
  analytics, or any third party.
- The optional bigger-model fallback (Groq free endpoint) only receives the
  **OCR text**, never the photo — and only when you add the key yourself.
- **Delete means delete**: the 🗑️ button removes the photo, text, audio and
  result row immediately. There is no backup, no trash, no recovery.
- No accounts, no tracking cookies, no analytics scripts in the app.
- Family history is PIN-lockable (`FAMILY_PIN`) so a shared link still keeps
  the diary private.
